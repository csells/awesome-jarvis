# History

Retired, archived and discontinued projects that shaped real-life Jarvis. They're kept here for reference and are no longer recommended for new builds.

## Assistants

- [Mycroft](https://github.com/MycroftAI/mycroft-core) - Pioneering open-source smart-speaker assistant, carried on by OpenVoiceOS and Neon after the company folded.
- [Rhasspy](https://github.com/rhasspy/rhasspy) - Offline, multilingual voice assistant toolkit whose ideas and author moved into Home Assistant's Wyoming and Piper stack.
- [01](https://github.com/openinterpreter/01) - Open Interpreter's voice interface for controlling computers from desktop, phone or ESP32, now dormant.
- [Microsoft JARVIS](https://github.com/microsoft/JARVIS) - Code for HuggingGPT, the 2023 research system in which an LLM dispatches tasks to Hugging Face models.
- [Humane AI Pin](https://fortune.com/2025/02/19/hp-humane-deal-ai-pin-shutting-down/) - Screenless AI wearable, bricked in February 2025 after HP bought Humane's assets.
- [Limitless Pendant and Rewind](https://rewind.ai/what-happened-to-rewind/) - Lifelogging memory products, discontinued after Meta acquired Limitless in December 2025.

## Components

- [Snowboy](https://github.com/Kitt-AI/snowboy) - Early customizable hotword detector whose service shut down in 2020.
- [Mycroft Precise](https://github.com/MycroftAI/mycroft-precise) - Lightweight RNN wake word listener behind "Hey Mycroft".
- [py-webrtcvad](https://github.com/wiseman/py-webrtcvad) - Python bindings for Google's classic WebRTC voice activity detector.
- [Coqui TTS](https://github.com/coqui-ai/TTS) - The original home of XTTS, frozen after Coqui shut down in early 2024. See the Idiap fork in the main list.
- [rhasspy/piper](https://github.com/rhasspy/piper) - Original Piper repository, archived in favor of the Open Home Foundation's piper1-gpl.
- [wyoming-satellite](https://github.com/rhasspy/wyoming-satellite) - Original Wyoming voice satellite, replaced by Linux Voice Assistant.
- [Vocode](https://github.com/vocodedev/vocode-core) - Early modular library for LLM voice agents.
- [Sesame CSM](https://github.com/SesameAILabs/csm) - Open base of Sesame's conversational speech model, which set the bar for natural prosody in 2025.
- [GLM-4-Voice](https://github.com/zai-org/GLM-4-Voice) - Early open end-to-end Chinese and English spoken dialogue model.
- [Supertonic](https://github.com/supertone-oss-archive/supertonic) - Fast on-device multilingual text-to-speech, archived by Supertone in 2026.
- [AutoGen](https://github.com/microsoft/autogen) - Pioneering multi-agent conversation framework, in maintenance mode since Microsoft Agent Framework replaced it.
- [Open Interpreter (Python)](https://github.com/endolith/open-interpreter) - Community fork of the original Open Interpreter with OS mode, after the main project became a Rust coding agent.

## Interfaces

- [eDEX-UI](https://github.com/GitSquared/edex-ui) - The canonical sci-fi fullscreen terminal and system monitor, inspired by TRON Legacy.
- [Arwes](https://github.com/arwes/arwes) - Futuristic sci-fi web UI framework with animated frames, glows and sounds, no longer maintained as of 2026.
- [OpenGlass](https://github.com/BasedHardware/OpenGlass) - About $25 in parts to turn any glasses into AI camera glasses, dormant since 2025.
