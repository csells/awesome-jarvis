# OpenDots candidate triage — 2026-10-05

Follow-up: [partial hands-on tests](../../lab/evidence/opendots/README.md) now support Watch List placement. The source-only triage below records the earlier assessment; its statement that no tests were run applies only to that initial stage.

Assessed CopilotKit/OpenDots, the likely project intended; several unrelated OpenDots repositories exist. Source pinned at `71efd82cd883df7b107d663bd36435a1d8a2d12a`. Two independent source readings inform this triage; no local build, voice call or connected-service test was run. This is not a published scorecard entry.

## Verdict

Promising candidate for the Watch List after hands-on testing, not presently a strong Jarvis recommendation. It is a real MIT-licensed application template with useful dashboard and call infrastructure. Its strongest evidence is visual; voice is click-to-call, and supervision is limited to specialist compute and scheduled work rather than automatic multi-agent coordination.

## Evidence

- **Voice: partial.** Realtime session config enables semantic VAD, speech responses and interruption. Calls are explicitly started, expire after 15 minutes and permit six compute requests. No wake/background listener was found. This is implementation evidence, not verified barge-in behavior. [Server](https://github.com/CopilotKit/OpenDots/blob/71efd82cd883df7b107d663bd36435a1d8a2d12a/src/server/voice.ts), [client](https://github.com/CopilotKit/OpenDots/blob/71efd82cd883df7b107d663bd36435a1d8a2d12a/src/client/useVoice.ts).
- **Hands-free: limited.** Once a call starts, speech is continuous, but the speech model exposes only `ask_compute`. No dedicated spoken approval, denial or task-cancellation path was found. Interrupting speech is not compute cancellation. Ending a call aborts pending compute. Approval uses a browser card. [Voice tools and abort lifecycle](https://github.com/CopilotKit/OpenDots/blob/71efd82cd883df7b107d663bd36435a1d8a2d12a/src/server/voice.ts), [approval card](https://github.com/CopilotKit/OpenDots/blob/71efd82cd883df7b107d663bd36435a1d8a2d12a/src/client/PageReviewCard.tsx).
- **Visual: strong code evidence.** Web workspace includes specialist Dots, documents, activity, task controls, computer panels and call captions/states. Rendering has not been inspected live in this assessment. [Workspace](https://github.com/CopilotKit/OpenDots/blob/71efd82cd883df7b107d663bd36435a1d8a2d12a/src/client/App.tsx), [call view](https://github.com/CopilotKit/OpenDots/blob/71efd82cd883df7b107d663bd36435a1d8a2d12a/src/client/CallView.tsx).
- **Oversight: partial.** Speech delegates to the selected specialist in the same persistent conversation. Scheduled work has controls, but the runner serializes active tasks and bounds execution to 90 seconds. README explicitly leaves automatic delegation and multi-Dot group conversations for future work. [Runner](https://github.com/CopilotKit/OpenDots/blob/71efd82cd883df7b107d663bd36435a1d8a2d12a/src/server/runner.ts), [limitations](https://github.com/CopilotKit/OpenDots/blob/71efd82cd883df7b107d663bd36435a1d8a2d12a/README.md#features).

## Service dependencies and verification gaps

MIT license is present. The self-hosted app requires configured CopilotKit Intelligence and model access for conversations; voice separately calls OpenAI Realtime. No subscription-authenticated Claude/Codex CLI adapter was found. That is a stock integration limitation, not proof that an adapter cannot be written. Public-web research defaults to Parallel. Optional computers use OpenBot services. [Configuration](https://github.com/CopilotKit/OpenDots/blob/71efd82cd883df7b107d663bd36435a1d8a2d12a/.env.example), [license](https://github.com/CopilotKit/OpenDots/blob/71efd82cd883df7b107d663bd36435a1d8a2d12a/LICENSE).

The README reports live basic realtime speech checks but explicitly says spoken compute delegation and Slack still need connected-service verification. Those are upstream statements, not our test results. Before inclusion, test speech interruption versus compute cancellation, actual delegated results, approval behavior across voice/browser, and persisted background work. This triage does not claim a full security audit or completed activity/maintainer review.
